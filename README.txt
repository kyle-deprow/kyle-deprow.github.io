James DeProw — portfolio

Static personal portfolio for James DeProw, hosted with GitHub Pages from the
repository root. The site is plain HTML, CSS, and the lightweight JavaScript
included with the original template; it has no build step.

To preview locally:

    python3 -m http.server 8000

Then open http://localhost:8000/.
